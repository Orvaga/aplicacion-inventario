🚀 OPCIÓN 1: DESPLIEGUE AUTOMÁTICO (RECOMENDADO)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Abre PowerShell en la carpeta del proyecto y ejecuta:

    .\deploy-to-github.ps1

El script te guiará paso a paso para:
1. Inicializar Git
2. Hacer commit
3. Conectar con GitHub
4. Subir el código

Luego solo necesitas:
1. Ir a https://render.com
2. Crear Web Service desde tu repositorio
3. ¡Listo!


🔧 OPCIÓN 2: DESPLIEGUE MANUAL

PASO 1: Subir a GitHub
─────────────────────────────────────────────────────────────────

cd d:\huilawed\aplicacion_app

git init
git add .
git commit -m "Initial commit - Aplicación de inventario"

# Crear repositorio en: https://github.com/new
# Nombre sugerido: aplicacion-inventario

git remote add origin https://github.com/TU_USUARIO/aplicacion-inventario.git
git branch -M main
git push -u origin main


PASO 2: Desplegar en Render
─────────────────────────────────────────────────────────────────

1. Ve a: https://render.com
2. Regístrate/Inicia sesión con GitHub
3. Click "New +" → "Web Service"
4. Selecciona tu repositorio: aplicacion-inventario
5. Configura:

   Name:          aplicacion-inventario
   Environment:   Python 3
   Build Command: pip install -r requirements.txt && python backend/create_database.py
   Start Command: gunicorn -w 4 -b 0.0.0.0:$PORT backend.run:app
   Plan:          Free

6. Click "Create Web Service"
7. Espera 5-10 minutos

🆘 SOLUCIÓN DE PROBLEMAS

   → Verifica logs en Render
